final case class Voice(id: String, name: String, tag: String, local: Boolean)

A voice of the browser's, in which it says text aloud.

A voice of the browser's, in which it says text aloud.

Value parameters

id

What tells it apart from the browser's other voices.

local

Whether it speaks on the device itself, rather than through an online service of the browser's maker, which is sent what it says.

name

Its name, as the browser shows it.

tag

The BCP 47 tag of the language it speaks, as the browser gives it.
