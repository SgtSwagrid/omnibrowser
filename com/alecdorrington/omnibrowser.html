abstract class BrowserExtension[P]

A browser extension, defined by an object extending this class, which the sbt-omnibrowser plugin builds for each target browser.

A browser extension, defined by an object extending this class, which the sbt-omnibrowser plugin builds for each target browser.

Each part of the extension, its background, contentScripts, popup and options, is a method, so that it is built only when that part starts, and its code is bundled only where it runs. A content script's bundle holds what its own method reaches, and whatever the object's own values reach, so they should be only what every part shares, such as its Messages and StorageKeys.

Type parameters

P

The extension's permissions, as an intersection of Permission types such as Permission.Storage & Permission.Tabs, or Any for none. They are requested in the extension's manifest, and the code within the extension may use only the APIs that they grant.
